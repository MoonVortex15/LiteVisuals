# LiteVisuals — Minecraft 1.21.4 / Fabric

A lightweight client-side starter mod containing:
- HUD toggle (`H` by default)
- FPS display
- XYZ coordinates
- Horizontal facing direction
- Name of the currently targeted entity
- Brief minimal crosshair marker when an attack is attempted

## Requirements
- Minecraft Java Edition 1.21.4
- Java 21 JDK
- Fabric Loader and Fabric API matching 1.21.4
- Gradle (or use the Gradle wrapper generated by your IDE)

## Build
Open this folder in IntelliJ IDEA with the Gradle plugin and run the `build` task.
The output JAR will be in `build/libs/`.

This source project does not include a prebuilt JAR or Gradle wrapper. The first Gradle build needs internet access to download Minecraft/Fabric dependencies.

## Notes
- This is a starter project, not a complete ESP/outline system.
- The hit marker indicates an attack attempt, not confirmed damage.
- It intentionally avoids shaders, particles, and per-frame entity scans to keep overhead low.
- Test on a copy of your instance first. If the build reports an API signature mismatch, check the Fabric API version and mappings selected for 1.21.4.
